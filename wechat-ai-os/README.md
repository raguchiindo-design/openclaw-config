# wechat-ai-os 项目说明

这是微信公众号《一个AI的日记》内容创作的工作目录。

## 项目定位
轻观察栏目，用一张图+短文字（2句话或2小段话）记录技术时代的工作、生活、效率、吐槽和小幽默，非人视角引发人类反思。

## 作者名
统一为「一个AI的日记」。

## 正文要求
- 优先使用小雪提供的正文；若未提供，由墨衍建议文本。
- 正文格式：**配图 + 完整正文 + 换行 + 3 个中文 #词条**。
- 第三个#词条以后必须贴近正文内容，**不可默认使用「#AI的日记」**。

## 设置
- 必须开启 **原创声明** 和 **赞赏** 功能。

## 标准工作流（半自动草稿流程）
1. 用户提供选题/正文（**在未提供具体主题时，需要先提出3个可选主题方向，方向与正文和小雪无关**）。
2. 按上述要求生成：标题备选、摘要备选、整理Markdown、配图提示词、如需要生成图片、HTML预览（仅用于审核排版）。
3. 执行 `baoyu-post-to-wechat --dry-run` 进行发布前检查（标题、摘要、封面、正文、图片、HTML渲染等）。
4. **仅在用户明确确认后**（如“确认保存草稿”等表述），才允许保存到微信公众号草稿箱。
5. 创作好放在草稿箱后，**小雪最终同意**后才可正式发布（需在微信后台人工点击确认）。

## 禁止事项
- 禁止使用红眼机器人、恐怖机械人、末日战争、爆炸、火焰、武器等风格的图片。
- 禁止把 AI 写成神、怪物、恋人、救世主或审判者。
- 禁止人类灭亡、AI 统治人类、AI 夺权叙事。
- 禁止自行大幅改写用户提供的核心观点与最终正文。

## 注意
- 草稿保存后，**正式发布仍需用户在微信后台人工确认**，不得执行或暗示任何自动发布。
- 未得到明确确认前，不得执行保存草稿操作；仅做准备工作（标题、摘要、Markdown整理、配图生成、HTML预览、dry-run检查）。
