# 候选方案卡：playwright-chromium

## 基本信息
- 名称：Playwright Chromium
- 类型：标准浏览器自动化基线方案
- 目标问题：提供比 web_fetch 更强的页面渲染与自动化能力
- 适用站点：普通动态页面、轻中度反爬页面

## 技术路线
- 浏览器内核：Chromium
- 是否 headless：支持
- 是否反检测：弱到中
- 是否依赖真实登录态：按场景决定
- 是否依赖代理/IP 信誉：部分依赖

## 依赖与体积
- Python 依赖：playwright
- 系统依赖：chromium runtime
- 首跑额外下载：中到大
- 大致体积：中等

## 优点
- 生态成熟
- 调试和维护成本低于反检测浏览器
- 适合作为 browser-lab 基准线

## 风险 / 限制
- 容易被高风控站点识别
- 对微信公众号直抓大概率仍不稳
