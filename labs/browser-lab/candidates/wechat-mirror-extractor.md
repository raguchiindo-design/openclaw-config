# 候选方案卡：wechat-mirror-extractor

## 基本信息
- 名称：微信公众号镜像/替代源提取
- 类型：轻量内容提取方案
- 目标问题：以最低成本获取微信公众号正文
- 适用站点：mp.weixin.qq.com 文章内容读取与存档

## 技术路线
- 浏览器内核：无强依赖
- 是否 headless：不依赖
- 是否反检测：绕开直抓，通过镜像站/替代源
- 是否依赖真实登录态：否
- 是否依赖代理/IP 信誉：弱

## 依赖与体积
- Python 依赖：很少或无
- 系统依赖：低
- 首跑额外下载：低
- 大致体积：轻量

## 优点
- 成本最低
- 适合 cron、存档、阅读
- 对当前主环境最友好

## 风险 / 限制
- 不一定总有镜像
- 内容可能有延迟、格式偏差
- 无法覆盖所有最新文章
