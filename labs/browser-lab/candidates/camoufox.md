# 候选方案卡：camoufox

## 基本信息
- 名称：Camoufox
- 类型：反检测浏览器
- 目标问题：提升云端浏览器在高风控页面上的通过率
- 适用站点：部分强反爬页面、微信公众号实验性直抓

## 技术路线
- 浏览器内核：Firefox 改造版
- 是否 headless：支持
- 是否反检测：是
- 是否依赖真实登录态：不一定，但高风控站点通常仍受益于真实登录态
- 是否依赖代理/IP 信誉：是，不能单独解决机房 IP 信誉问题

## 依赖与体积
- Python 依赖：camoufox, playwright, browserforge 等
- 系统依赖：浏览器运行时
- 首跑额外下载：大（已观测约 713MB）
- 大致体积：重型

## 优点
- 反检测方向明确
- 比普通 headless 更像真人浏览器

## 风险 / 限制
- 依赖重
- 首跑下载大
- 不保证解决微信公众号 / 机房 IP 问题
- 当前更适合实验层，不适合直接做默认层
